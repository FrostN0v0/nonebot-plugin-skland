# MAA 远程控制

管理员启用模块后，可以通过 QQ 官方 bot 操作电脑上的 MAA。MAA 需要持续运行并开启远程控制。

## 绑定

1. 在 QQ 私聊或群聊发送 `/MAA绑定`，打开机器人回复的网页。
2. 网页填写设备标识符，位置：**MAA设置-远程控制-设备标识符**。
3. 回到原 QQ 会话，核对网页校验码一致，由发起绑定的本人点击“确认绑定”。未出现按钮时发送 `/MAA绑定 查询`。
4. 回到提交申请的原浏览器，点击领取连接设置，将两个端点和用户标识符填入 MAA。
5. 将轮询间隔设为 5000 毫秒，启用远程控制，15 分钟内测试连接；首次连接成功后 bot 通知原会话，发送失败时也可用 `/MAA状态` 确认在线。

用户标识符是连接密钥，请勿转发。首次连接须在 15 分钟内完成；过期后重新生成即可。一个用户绑定一台设备，更换设备前在群聊或私聊发送 `/MAA解绑`，只能解绑自己的设备。

申请链接十分钟有效，设备标识符必须与首次连接的设备一致，带横杠和不带横杠的同一 UUID 均可识别。密钥只在获确认的浏览器领取一次，不发到 QQ。
其他人点击按钮、在其他会话确认或换浏览器均不能领取这份密钥。领取失败或刷新后丢失设置时重新申请；已连接的设备须先解绑。
请只确认自己打开的网页校验码；别人打开群内链接也能提交申请，切勿替别人的网页确认。

## 菜单

发送 `/maa`，点击竖排按钮直接进入下一级菜单，无需再发送指令。

```text
/maa（群聊 / 私聊）
├─ 绑定设备
├─ 状态与截图
│  ├─ 在线状态
│  ├─ 获取截图
│  ├─ 最近结果 / 截图
│  ├─ 任务心跳
│  └─ 返回主页
├─ 执行任务
│  ├─ 一键长草
│  ├─ 刷理智
│  ├─ 基建 / 公招
│  │  ├─ 基建换班
│  │  ├─ 自动公招
│  │  └─ 返回任务
│  ├─ 其他任务
│  │  ├─ 唤醒游戏
│  │  ├─ 信用购物
│  │  ├─ 领取奖励
│  │  ├─ 自动肉鸽
│  │  └─ 返回任务
│  └─ 返回主页
├─ 停止与解绑
│  ├─ 立即停止
│  ├─ 解绑设备
│  └─ 返回主页
└─ 使用说明
```

群聊和私聊使用相同菜单，直接指令也均可使用。解绑会同时撤销本人尚未领取的网页绑定申请。

菜单只接受发起者在当前会话操作，十分钟后过期，使用一次后需使用新菜单。机器人重启后请重新发送 `/maa`。

也可以直接发送 `/MAA状态`、`/MAA结果`、`/MAA截图`、`/MAA停止`、`/maa 心跳` 或 `/maa 开始 基建`。

## 任务结果

任务结果会主动回复到发起会话，发送失败时可通过 `/MAA结果` 查询。**群内发起的结果和截图会显示给群成员**。

- 一键长草及各子任务沿用 MAA 本机配置，请先确认理智药、源石、公招及信用购物设置。
- MAA 回报 SUCCESS 时显示“执行已结束”。原生协议没有提供正常完成、本机停止或异常结束的具体原因。
- MAA 回报 FAILED 时显示“执行失败”。停止请求发出后，通过后续心跳确认是否空闲，未确认时会如实提示。
- 设备断线、未领取指令过期和等待回报超时分别提示，不将它们算作执行成功。
- 任务记录、通知、日志与截图保留三天，设备绑定保留至解绑。解绑会撤销密钥，但不能保证已经领取的任务立即停止。

本轮仅支持 QQ 官方 bot，非官 bot 留待后续开发。
